## 1. Excel Basics for Data Analysis

**📂 Folder:** `Excel Basics for Data Analysis/`

An introduction to data analysis using Microsoft Excel, covering the essential tools needed to clean, organize, and summarize datasets before moving into code-based workflows.

**Topics covered:**
- Data cleaning: removing duplicates, handling blanks, formatting
- Pivot Tables and Pivot Charts for summarizing data
- Formulas: `VLOOKUP`, `IF`, `COUNTIF`, `AVERAGE`, `SUM`
- Filtering, sorting, and conditional formatting

**Tools:** Microsoft Excel

## 7. Data Science Capstone — SpaceX Falcon 9

**📂 Folder:** `Data Science Capstone project content/`

The final capstone simulates a real-world data science engagement. Playing the role of a data scientist at a startup competing with SpaceX, the objective is to **predict whether the Falcon 9 first stage will successfully land** — a key factor since reusability allows SpaceX to offer launches at \$62M vs. competitors' \$165M+.

### Project Phases

| Phase | Description |
|---|---|
| **Data Collection** | SpaceX REST API calls + BeautifulSoup web scraping |
| **Data Wrangling** | Cleaning, encoding, handling nulls, feature engineering |
| **EDA with SQL** | SQLite queries to explore launch patterns and outcomes |
| **EDA with Python** | Pandas & Seaborn visualizations of payload, orbit, and site data |
| **Interactive Visuals** | Folium launch site maps + Plotly Dash analytics dashboard |
| **Machine Learning** | Logistic Regression, SVM, Decision Tree, KNN — tuned via GridSearchCV |
| **Presentation** | Business-style report summarizing findings for stakeholders |

### Key Questions Answered
- Which launch sites have the highest success rates?
- Does payload mass affect landing success?
- How have success rates improved over time?
- Which ML model best predicts a successful landing?

**Tools:** Python, Pandas, Scikit-learn, Plotly Dash, Folium, BeautifulSoup, SQL (SQLite), Jupyter Notebook
